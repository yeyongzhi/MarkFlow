# 功能清单

以下描述当前实现。Windows 核心编辑和文件流程已有自动化验证；安装升级、macOS 和特殊输入情况仍需进一步验收。

| 分类 | 功能 |
| --- | --- |
| 工作区 | 多文件夹、按需展开目录、独立 Markdown 文件、文件名快速打开 |
| 文档管理 | 多标签、固定与排序、最近与收藏、新建、重命名、移动、归档和恢复 |
| 编辑 | 可视化、源码、分屏、阅读预览；跨视图撤销/重做 |
| Markdown | 标题、列表、引用、代码、GFM 表格/任务列表/删除线、公式、Mermaid 图表 |
| 写作 | 大纲跳转、查找替换、语法辅助、斜杠命令、模板、打字机位置、专注模式 |
| 查找整理 | 工作区全文搜索、文档标签、最近文件、收藏 |
| 图片 | 本地插入、粘贴/拖入、替换、描述、路径查看、失效图片修复 |
| 保存保护 | 自动/手动保存、冲突提示、恢复草稿、历史快照、工作区备份 |
| 格式 | UTF-8、UTF-8 BOM、带 BOM 的 UTF-16LE/BE，LF/CRLF |
| 导出 | HTML、PDF、带图片附件的 Markdown ZIP |
| 外观 | 亮/暗/系统模式、主题色、实色/柔和/玻璃材质、字体字号、圆角、密度 |
| 桌面 | 窗口状态恢复、可选关闭到托盘、手动检查发布信息 |

## 当前边界

- 单篇文档和单张图片上限 20 MiB，图片支持 PNG、JPEG、GIF、WebP。
- 默认不加载远程图片，不跟随符号链接或目录联接。
- PDF 使用图像分页，文字不能像普通文本 PDF 那样选择复制。
- 移动文件会处理部分受管理的附件引用，不会全面重写所有入站链接。
- 锁屏不加密磁盘文件，不能代替磁盘加密或系统账号权限。
- 尚无云同步、协作编辑或完整的附件集中管理界面。
