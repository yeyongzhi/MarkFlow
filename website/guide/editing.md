# 编辑与阅读

## 四种视图

| 视图 | 适合的场景 |
| --- | --- |
| 可视化编辑 | 直接查看排版并编辑，减少 Markdown 符号干扰 |
| 源码编辑 | 精确控制原始 Markdown，检查链接和空白格式 |
| 分屏编辑 | 一侧修改源码，一侧查看渲染结果 |
| 阅读预览 | 只读查看当前文章的排版 |

四种视图共用同一份文档内容。可视化编辑器在实际编辑后可能规范化空格、列表和链接写法；需要严格保留原始格式时使用源码编辑。

## 图片、公式与图表

通过文章工具栏插入本地图片，也可粘贴或拖入。附件保存在工作区内，Markdown 使用相对引用。删除图片引用不会自动删除附件文件。

支持 KaTeX 公式和 Mermaid 图表。图表语法错误时会显示错误提示，可以检查源码后重试。

## 调整工作台

设置 → 外观中可以选择明暗主题、材质、圆角和密度；设置 → 写作中的正文排版与源码设置调整字体、字号和行高。毛玻璃模糊应用内部背景，不透出桌面壁纸。

## 导出

通过导出菜单选择 HTML、PDF 或 ZIP。HTML 适合浏览和复制内容；PDF 适合保留视觉排版，但当前文字以图像方式输出；ZIP 包含 Markdown 和本地图片附件。
