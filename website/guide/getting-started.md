# 开始写作

## 添加笔记文件夹

启动桌面程序，点击“添加工作区”，选择已有笔记文件夹或新建一个文件夹。MarkFlow 直接读取其中的 Markdown 文件，文件仍位于原目录。

可同时添加多个工作区。仅打开文档或切换编辑视图不会改写原文件。

## 打开和新建文档

单击文件树中的文章即可打开。每篇文章保留独立标签，不会被下一篇自动替换；再次打开同一篇会激活已有标签。

通过文件菜单新建文档，可选择日记、会议记录、项目笔记等模板。文件菜单也支持打开独立文件、最近和收藏。

## 写作与保存

选择适合你的[编辑视图](./editing)。默认停止输入约 500ms 后自动保存；设置中可以调整延迟或关闭自动保存。

磁盘文件被其他程序修改时，应用暂停覆盖并提示冲突。请先比较内容，再决定合并或覆盖，勿把冲突提示当成普通保存完成。

## 搜索和整理

- `Ctrl / Cmd + P`：快速打开文档。
- `Ctrl / Cmd + F`：当前文档查找替换。
- `Ctrl / Cmd + Shift + F`：工作区全文搜索。
- `Ctrl / Cmd + K`：搜索命令。

使用最近、收藏、文档标签和大纲定位内容。删除文章时优先归档，需要时从归档入口恢复。
