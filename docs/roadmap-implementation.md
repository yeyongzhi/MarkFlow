# 红框功能验收清单

范围：用户六张图片中红框内的项目。第六张没有红框，本轮把保存、图片、标签、移动和性能回归作为验收，未增加跨平台发布或安装包验证任务。

## 保存与数据安全

| 项目 | 实现与入口 |
| --- | --- |
| 统一撤销与重做 | 编辑菜单、Ctrl+Z/Shift+Z；输入分组，格式、图片、标签、整理分别记录；切换视图保留历史 |
| 保存状态 | 页脚及文档提示：已保存、未保存、保存中、失败、外部修改；重试、比较、另存副本 |
| 历史版本 | 文件菜单，按内容变化保存快照；列表时间/原因，正文预览、左右比较、恢复并撤销；重命名与移动迁移历史 |
| 外部修改冲突 | 比较当前与磁盘，编辑合并结果；保留当前并备份磁盘或另存副本；再次检查哈希 |
| 崩溃恢复 | 延迟写入恢复草稿；启动显示来源、时间、正文预览；恢复、丢弃，丢弃也有备份 |
| 危险操作可恢复 | 文件/目录删除、批量标签及编码转换产生备份；文件菜单 → 工作区备份与操作恢复 |
| 工作区备份 | 手动或应用运行期间定时；包含文档、附件、归档；设置目录与保留数量 |
| 保存策略 | 设置 → 保存与备份，自动保存延迟、失焦、关闭前保存；失败退出前保护草稿 |
| 编码和换行 | UTF-8/BOM、UTF-16LE/BE BOM、LF/CRLF 检测、保留、显式备份后转换 |
| 文件异常 | 只读错误、保存失败保留正文和另存入口；失效目录重新连接；磁盘空间错误明确提示 |

删除恢复不覆盖后来重新创建的同名文件/目录；标签与格式恢复拒绝覆盖再次修改的文件。历史列表读取元数据索引，选择版本才读取正文。单次备份上限 5GiB / 100000 项，达到上限时给出错误并保留原文档。

## 文档打开与导航

| 项目 | 实现与入口 |
| --- | --- |
| Ctrl+P | 按文件名与路径做子序列匹配、排序，方向键选择 |
| 最近文档 | 文件菜单 / 工作区栏，跨启动保留，可移除单条或清除失效记录 |
| 收藏文档 | 文件菜单收藏，文件栏查看，跨启动保留 |
| 单击预览、双击固定 | 文件树临时标签复用；编辑或双击后保留；并发打开去重 |
| 标签管理 | 拖动排序、右键固定、关闭其他/全部、Ctrl+Shift+T 重新打开 |
| 前进后退 | Alt+左右；记住文档与光标/跳转位置 |
| 文件树定位 | 工作区栏“定位”、视图菜单；可启用自动展开和定位 |
| 工作区导航 | 文件树展示全部工作区；展开状态持久化；按后续设计移除侧栏下拉选择 |
| 独立文件 | 文件 → 打开本地 Markdown 文件，不要求先添加工作区 |
| 文件/目录拖入 | 原生窗口拖入文档打开；拖入目录添加工作区 |

- verify-safety.mjs：原始字节恢复、历史迁移、UTF-16 图片路径改写和批量标签、删除二进制/空目录恢复、丢弃草稿恢复、失效记录、窗口尺寸保存。
- verify-interactions.mjs：自定义颜色对比、专注退出、820px 视口折叠、前进后退、托盘隐藏保护草稿和几何保存。
- 图片、基础原生文件/导出、旧 UI 设计回归已通过。
- verify-performance.mjs：858018 字符编辑保存、15 标签没有后台可视化引擎、正则超时与 1024px 设置无横向溢出通过。
- verify-archive-tags.mjs：文档标签增删、未知 front-matter 字段保留、普通与归档批量标签同步、行高、同名恢复、彻底删除、旧哈希拒绝与 BOM/CRLF 保留通过。

真实多显示器拔插/各 DPI 比例、macOS/Linux、磁盘耗尽和生产更新服务没有环境实测；相应行为实现与模拟/隔离回归不等于这些硬件及发布环境已验收。更新检查内置 GitHub Releases，点击检查时联网；仍需发布者公开正式 Release 和安装包。已接入 Tauri updater 签名下载和安装，并验证本地签名安装包构建；实际跨版本升级仍待验收。


## 后续侧栏调整

移除“全部工作区”下拉框和独立搜索按钮；搜索图标与刷新、添加共用工作区标题行。最近与收藏改为侧栏内标签页，下方列表独立滚动，支持打开与移除记录。定位按钮改为带说明的图标，展开目录、滚动并聚焦当前文档；独立文件禁用此入口。原生 verify-sidebar.mjs 验证以上行为，以及失效工作区筛选不会隐藏文件树，820px 视口无侧栏横向溢出。


## 工作区搜索修复

侧栏搜索现在同时匹配文件名、相对路径与正文。文件匹配显示“文件名或路径匹配”，排在正文行匹配之前；打开文件匹配保留编辑视图，正文匹配切换源码并跳转行。已打开文件使用当前正文替代磁盘搜索结果，避免未保存修改被遗漏。区分大小写同时作用于文件与正文。Ctrl+P 仍只用于文件名/路径快速打开。

verify-workspace-search.mjs 在原生隔离数据中验证：正文不含 test 的 test.md、嵌套目录路径、正文匹配行、已打开文件、未保存修改、陈旧磁盘正文排除、大小写开关及 Ctrl+P 范围。


## 收藏入口与材质外观调整（2026-10-04）

- 最近/收藏侧栏不再显示移除按钮，记录管理仍可通过文件菜单访问。
- 文件树和文章操作菜单支持收藏、取消收藏，共用持久化记录并同步侧栏。
- 标签页移除斜体的末尾裁切，将名称主体和后缀分别布局；长名称只截断主体，后缀保留，完整名称可访问。
- 外观增加简洁/柔和/毛玻璃材质、0/8/12/18px 圆角，以及毛玻璃模糊强度；实时应用、保存，分类重置包含这些选项。
- 材质使用全局主题 token 和 Tailwind 工具类，门户弹窗及第三方编辑器背景通过全局 CSS 适配，没有新增 Vue style 标签。毛玻璃模糊界面后面的背景，不模糊正文，也不是操作系统桌面透视效果。
- verify-materials.mjs 原生验证菜单收藏同步、持久化、侧栏移除隐藏、短/长文档后缀可见、模糊强度、圆角和窄视口。侧栏及长文档性能回归通过。
