## 4. 当前边界

- macOS 运行、废纸篓、Apple Silicon / Intel 产物、签名和公证均未实测；Windows 安装流程也未执行。
- 所见即所得实际编辑后可能规范化 Markdown 写法。原文精确编辑用源码视图；复杂 HTML 与非标准扩展在两种内核中可能有差异。
- 仅支持 UTF-8，文档 / 单图 20MiB；支持 PNG、JPEG、GIF、WebP。本地核心资源不依赖 CDN，远程图片默认不加载。
- 同工作区移动仅修复被移动文档的根目录 `assets/` 图片引用；其他链接需要自行核对。不跟随符号链接或 Windows 目录联接。
- 未完成移动保留恢复日志并提示，尚无自动事务恢复界面。配置迁移、备份 / 草稿自动清理、全面的大规模性能压测尚未完成。
- 当前不是多进程协作编辑器；哈希检查与文件替换之间仍有外部竞争窗口，无法承诺消除所有不协作程序的并发写入。
