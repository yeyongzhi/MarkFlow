# 本轮功能与使用入口

本轮对应 2026-10-04 六张截图的红框范围。

## 隐私锁屏

设置 → 隐私与锁屏：设置、修改、移除密码。标题栏右侧锁图标立即锁定；尚未配置密码时进入密码设置。配置后启动自动锁定。锁定前保护草稿，锁定时卸载编辑界面和弹窗，阻止应用数据命令调用。错误密码连续尝试触发等待。

密码保存为带随机盐的 Argon2 哈希，不保存明文。锁屏用于界面隐私，磁盘文件不会因此加密。

## 文档导航

设置 → 通用：最近文档显示数量与打开／编辑排序。标签栏管理按钮：搜索已打开文件并切换、关闭。标签右键菜单支持关闭左侧、右侧。同名文件显示父目录，扩展名独立保留；临时标签显示“预览”，双击或编辑后转为正式标签。

## Markdown 内容

文章操作 → 编辑表格：增删行列、列对齐、移动行列、导入电子表格复制的制表符数据。代码块自身“编辑 / 语言”入口与文章操作 → 编辑代码块均可打开指定代码块。Tab / Shift+Tab 支持整段缩进与反缩进，保留代码。

分屏和阅读预览支持 KaTeX 数学公式、Mermaid 图表、脚注及返回、提示块。长章节点击标题箭头可折叠；生成文档目录支持选择标题层级。公式和图表错误会显示源码及原因。未知语法和 HTML 原文保留；预览过滤脚本、内联样式和嵌入内容。含双向链接或 HTML 的文档使用分屏，避免可视化编辑器改写特殊语法。

斜杠命令加入公式、Mermaid、脚注和提示块。代码块工具条提供复制、换行、行号；外观设置提供默认换行、行号、高亮和代码配色。

HTML 导出内嵌公式字体和图表图片，支持离线查看；PDF 使用相同渲染结果，并保留脚注及目录的内部跳转链接。Markdown 打包仍保留原始 Markdown 与图片附件。

## 文档组织与标签

标题栏“工作区知识”入口包含项目首页、标签筛选、反向链接、相关文档、断链检查、关系图、语法说明。首页聚合最近、收藏、相关笔记、待办文档，可修改当前文档状态。

支持 `[[文档]]`、`[[目录/文档#章节|显示文字]]`，同名时使用目录路径。源码输入 `[[` 提供文档补全，输入 `#` 提供章节候选。普通 Markdown 章节链接也可跳转。重命名与移动会更新普通、引用和双向链接；代码示例不改写。修改前有副本，操作失败执行回滚或保留恢复材料。

点击正文工具栏的标签进入筛选，可组合全部满足、任意满足和排除标签。设置 → 标签管理可配置标签颜色，颜色只保存到偏好设置。

索引按需读取，最多 10,000 篇、50,000 个条目、约 32MiB 总内容，单文档超过 2MiB 时跳过并显示说明。默认忽略依赖、构建、版本控制和应用内部目录，拒绝符号链接及目录联接。关系图可切换当前工作区与当前文档的直接关联，展示前 120 篇文档。索引缓存约 10 秒，也可手动刷新。

## 主题与视觉

设置 → 外观：界面与正文主题独立；代码提供亮色、暗色、极地、暖纸配色；动效关闭、轻量、标准；支持降低材质效果，低核心数设备自动降低模糊。系统减少动态效果优先。新 UI 使用 Tailwind 和已有组件；第三方渲染器、动态主题变量及全局动效规则保留必要的共享 CSS，无新增 Vue style 标签。

## 验证

- 前端类型检查与生产构建。
- 前端单元测试覆盖新语法、目录、元数据、代码缩进，以及原有编辑和保存逻辑。
- Rust 单元测试覆盖链接重命名、代码示例保护、密码限流，以及原有文件安全。
- `scripts/verify-content-knowledge.mjs` 在隔离原生应用中验证公式、图表、错误回退、脚注、提示块、代码高亮、知识图谱、反链、标签组合、链接补全与跳转、目录、表格导入、链接更新、离线 HTML / PDF、主题、标签管理、锁屏和启动解锁。

Windows 原生应用已验证；其他平台以及不同实际显示器仍需专项验证。

本轮最终结果：39 项前端单元测试、12 项 Rust 单元测试通过；内容与知识、图片、搜索、界面设计和数据安全的隔离原生回归通过。生产构建与原生开发构建通过。
